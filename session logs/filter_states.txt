CONVENTIONS
-----------
- [MAP]     = map panel titlebar (lavender bar, id: map-status)
- [NETWORK] = network panel titlebar (dark bar, id: network-status)
- [SONGS]   = songs panel titlebar (mint bar, id: songs-title)
- [FOOTER]  = songs count strip at bottom of songs panel
- SONGS TABLE = what rows are shown
- MAP DIM   = which country bubbles are dimmed vs fully rendered
- NET DIM   = which nodes/edges are dimmed vs fully rendered in the network

- "dimmed" = 8% opacity (nearly invisible)
- "lit"    = full opacity
- "all songs" = all 2196 tracks, default sort year descending
- decade example used throughout: 1990s–2000s
- country example used throughout: Colombia
- solo genre example: folk latino (fine-grained node, single child group)
- group example: cumbia (multi-child group: cumbia, cumbia pop, cumbia digital, cumbia sonidera, electrocumbia, chicha)
- child example: electrocumbia (a child node inside the cumbia group, visible only when cumbia is expanded)

======================================================
SECTION 18 — EDGE CASES AND SPECIAL BEHAVIORS
======================================================

18.1 — Hover over map bubble (temporary, not a filter)
-------------------------------------------------------
What changes:         temporary dim of all other bubbles; tooltip shows country name + song count
On mouseout:          previous permanent state fully restored (no permanent dim change)

18.2 — Hover over collapsed group node (temporary)
---------------------------------------------------
What changes:         temporary dim of all unconnected group nodes and edges;
                      tooltip shows: name, cluster, song count, subgenre count, "click to expand"
On mouseout:          previous permanent state fully restored

18.3 — Hover over solo group node (temporary)
----------------------------------------------
What changes:         temporary dim of unconnected nodes;
                      tooltip shows: name, cluster, song count, edge list (came from / leads to)
On mouseout:          previous permanent state fully restored

18.4 — Hover over child node inside expanded group (temporary)
--------------------------------------------------------------
What changes:         temporary dim of unconnected child nodes + external nodes;
                      tooltip shows: name, cluster, song count, edge list
On mouseout:          previous permanent state fully restored

18.5 — Hover over edge (temporary)
------------------------------------
What changes:         hit line brightens the visible edge; tooltip shows source → target / type
On mouseout:          edge restored to EDGE_STYLES defaults; tooltip hides

18.6 — Songs column: genre column swap
----------------------------------------
When active:          when networkFilter is set (genre or genre-group), genre column → hidden, influence column → shown
When inactive:        genre column shown, influence column hidden

18.7 — Songs column: country column hide
-----------------------------------------
When active:          when mapFilter is set, country column → hidden
When inactive:        country column shown

18.8 — Navigation history — back/forward
-----------------------------------------
What restores:        full filter state snapshot (mapFilter, networkFilter, decadeMin, decadeMax);
                      for genre-group: group is re-expanded in network;
                      for genre (solo): network dim restored via applyNetworkDimByGenre;
                      table re-renders; titlebars recompute; decade slider UI updates

18.9 — Eponymous child (e.g. cumbia inside cumbia group)
----------------------------------------------------------
On expand:            the eponymous child (whose id = group label) becomes the anchor node;
                      group node <g> hidden entirely;
                      eponymous child renders at full opacity (0.85 fill, glow if >30 songs);
                      all other root children attach to it via anchor edges;
                      on collapse: group <g> visibility restored

18.10 — Peek nodes
--------------------
When shown:           when an expanded child connects to a fine-grained genre inside another multi-child group,
                      that specific fine-grained node appears as a peek node;
                      color = parent group's color (not its own cluster color);
                      fully interactive: hover shows edge list, click opens overlay and filters songs

18.11 — Solo group click behavior
-----------------------------------
What happens:         songs filtered to that single child genre;
                      no expansion animation;
                      group bubble stays at full size but dims unconnected group nodes;
                      expandedGroup is NOT set (remains null);
                      activeSelection = { type: 'node', nodeId: childId }

18.12 — Genre search finding a child node
-------------------------------------------
What happens:         parent group expands;
                      child node highlighted (lower opacity siblings);
                      search input holds the child id;
                      parent expansion triggers filterSongsGroup for all children first,
                      then highlight dims siblings to show only the matched child
